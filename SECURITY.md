# Security Policy

## About this project

This repository is a personal collection of Data Structures & Algorithms practice solutions in C++. It is not a library or a deployed service and has no releases, so there are no versioned security updates.

## Supported versions

Only the latest commit on the `main` branch is maintained.

| Version | Supported |
| --- | --- |
| `main` (latest) | ✅ |
| Older commits | ❌ |

## Reporting a vulnerability

If you find a security issue in this repository, such as a committed secret or credential, a malicious or unexpected binary, or code that could harm someone who builds and runs it, please report it privately:

1. Go to the repository's **Security** tab on GitHub.
2. Click **Report a vulnerability** to open a private security advisory.

Please do **not** open a public issue for security problems.

Include in your report:

- The file(s) and commit involved
- A description of the issue and its impact
- Steps to reproduce, if applicable

## What to expect

- I'll acknowledge your report within **7 days**.
- I'll review the issue and aim to fix confirmed problems within **30 days**.
- You'll be credited in the fix unless you'd rather stay anonymous.

## Out of scope

Bugs, wrong answers, or inefficient solutions are not security issues. Please open a regular issue or pull request for those.
